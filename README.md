# Chitram

Chitram is a responsive web application that allows users to explore the movie universe with ease. You can browse movies based on tags like Now Playing, Trending, Upcoming, and Top Rated of all time. Additionally, you can search for individual movies and access detailed information about each title — including overview, ratings, cast, crew, and trailers.

Users can bookmark movies under "Watch List" and "Seen List" to track their movie journey. Chitram also allows you to explore detailed profiles of cast and crew members and bookmark your favourite stars. All your curated lists — favourite stars, watch list, and seen list — are accessible in one place for a streamlined viewing experience. Built with clean design principles, RESTful API integration, and modern frontend practices, Chitram offers a smooth user experience across devices.


## Live Demo
🔗 [https://chitram.vercel.app/](https://chitram.vercel.app/)

## Features
- Browse movies in categories like Now Playing, Trending, Upcoming, and Top Rated.

- Search for movies by title.

- View movie details: overview, ratings, cast and trailers.

- Bookmark movies into "Watch List" and "Seen List".

- Explore profiles of cast and crew and bookmark favourite stars.

- Access all your lists in one place.

- Clean, minimalistic, responsive design.

- Optimized for both desktop and mobile.

- Fast performance and API error handling.


## Tech Stack
- **React** + **Tailwind CSS**
- **TMDB RESTful API**
- Deployed on **Vercel**

## Getting Started

```bash
git clone https://github.com/pardhu-og/Chitram
cd chitram
npm install

```
